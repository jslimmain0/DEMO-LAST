현재 서버와의 호환이 확인되지 않아 자동 업데이트는 사용할 수 없습니다.

다운로드는 로그인 없이 이용할 수 있습니다.

설치하고 바로 시작하세요

  1. 01

    설치 파일 실행

    MSI를 실행하고 설치 경로를 선택하세요. D 드라이브에도 설치할 수 있습니다.

  2. 02

    Windows 앱 열기

    시작 메뉴의 FlowLink를 실행하세요. 개인 워크플로는 내 PC에서 작업할 수 있습니다.

  3. 03

    회사 계정 연결

    앱에서 회사 서버 주소를 확인하고 로그인하면 팀 워크플로와 연결됩니다.

설치 위치와 데이터 위치는 별개입니다. 개인 데이터와 설정은 기본적으로 사용자 프로필에 저장됩니다.
