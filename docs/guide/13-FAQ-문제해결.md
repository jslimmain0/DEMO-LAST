# 13. FAQ · 문제 해결

[← 목차](README.md)

## 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| **노드가 실행 안 됨(건너뜀)** | 시작(START)에서 엣지로 연결되지 않았습니다. 캔버스의 `⚠ 미연결` 점선과 탑바 ⚠ 배지를 확인하세요 ([02장](02-에디터.md#편집-문제-배지--미연결-노드-찾기)). |
| **바인딩이 비어 있음** | 상위 노드의 응답 타입(키형/통짜형)과 예상 응답 필드 선언을 확인하세요. 통짜형(text/binary)은 `{{ body@노드 }}` 만 제공됩니다 ([04장](04-토큰-바인딩.md)). |
| **한글이 깨짐(레거시 연동)** | HTTP/TCP 노드의 **문자셋**(EUC-KR/MS949)을 지정하세요. 클라이언트(C→S) 모드는 브라우저 UTF-8 제약이 있으니 **서버(S→S) 모드** 권장 ([03장](03-노드-레퍼런스.md#api-호출-http)). |
| **콜백이 안 옴 (WAIT 타임아웃)** | ⚙ 설정의 **콜백 수신 주소**가 외부에서 도달 가능한지 확인(터널/도메인 필요할 수 있음). 급하면 실행 로그의 **테스트 콜백 → 보내기**로 흐름부터 검증 ([05장](05-실행-디버깅.md#콜백-대기-wait), [07장](07-트리거-자동화.md)). |
| **팝업이 안 열림 (FORM)** | 브라우저 팝업 차단. 폼 노드의 표시 방식을 **iframe 모달**로 바꾸면 차단 없이 페이지 안에 뜹니다 ([03장](03-노드-레퍼런스.md#폼결제창-열기-form)). |
| **Mock 이 404** | Mock 서버가 **꺼짐**이거나 slug/경로가 다릅니다. Mock 목록의 켜짐 토글, base URL, 라우트 매칭(위에서 첫 매칭)을 확인 ([10장](10-Mock-서버.md)). |
| **환경 변수가 안 먹음** | 탑바 🌐 스위처의 **활성 환경**을 확인하세요 — `없음(주입 안 함)` 이면 `{{ @env }}` 가 비어 나옵니다 ([06장](06-환경-시크릿-입력.md)). |
| **저장하려니 충돌(409) 안내** | 다른 사람이 먼저 저장했습니다. 새로고침 후 다시 적용하거나 덮어쓰기를 선택하세요. 잃은 내용은 버전 기록에서 복원 ([09장](09-버전-협업.md)). |
| **실행이 너무 오래 걸림** | 실행 로그에서 어느 노드가 시간을 쓰는지 확인(행별 ms). 외부 API 지연이면 타임아웃/재시도 정책을 상대 시스템과 조정하세요. 대기(WAIT) 노드는 타임아웃(초) 설정을 확인. |
| **단축키가 안 먹음(한글 모드)** | 물리 키 기준이라 정상 동작해야 합니다. **입력창에 포커스**가 있으면 복사/붙여넣기 등 편집 단축키는 브라우저 기본 동작이 우선합니다(`Ctrl+S`·`Ctrl+K` 는 항상 동작) — 캔버스를 한 번 클릭한 뒤 시도하세요. |

## 데이터는 어디에 저장되나요?

| 데이터 | 저장 위치 |
|---|---|
| 워크플로·버전·실행 이력·Mock 정의·시크릿·트리거 | **서버 DB** (팀 공유) |
| 환경(env)·즐겨찾기·테마·패널 크기·닉네임 | **브라우저 localStorage** (개인) |

## 알아두면 좋은 한계

- 진행 중이던 **대기(WAIT/입력/폼) 상태는 서버 재시작 시 소실**될 수 있습니다 — 다시 실행하세요.
- Mock 의 상태(state·seq)도 인메모리라 재시작 시 리셋됩니다.
- 스케줄러는 단일 서버 기준입니다. 콜백 서명 검증 같은 실 결제망 하드닝은 별도 과제입니다.
