# 14. 편의 기능 모음 — 알면 2배 빨라지는 것들

[← 목차](README.md)

FlowLink 곳곳에 숨어 있는 자잘한 편의 기능을 전부 모았습니다. 💎 표시는 UI 에서 잘 안 보이는 **숨은 기능**입니다.

> 자주 묻는 것부터: **"노드를 드래그하면서 복사(Alt+드래그)" 기능은 없습니다.**
> 대신 ⧉ 복제가 세 곳에 있습니다 — `Ctrl+D`, 노드 **우클릭 → ⧉ 복제**, 속성 패널 하단 **⧉ 복제** 버튼.
> 복제/붙여넣기는 +44px 어긋나게 배치되고 새 id 가 발급되며, **노드 안의 바인딩이 새 id 를 가리키도록 자동 치환**됩니다.

## 복사 · 복제 · 붙여넣기

| 기능 | 사용법 |
|---|---|
| 노드 복사/붙여넣기 | `Ctrl+C` / `Ctrl+V`. 다중 선택 시 선택 노드들 **사이의 연결(엣지)도 함께** 복사됩니다. |
| 💎 **워크플로 간 붙여넣기** | 클립보드가 브라우저 저장소 기반이라 A 플로우에서 복사 → B 플로우 열어 `Ctrl+V` 가 됩니다. 새로고침 후에도 유지. |
| 💎 붙여넣기 바인딩 자동 재매핑 | 붙여넣으면 새 id 가 발급되는데, 복사된 노드들끼리 참조하던 토큰(`{{ key@구노드 }}`, `@req:` 포함)과 칩이 **새 id 로 자동 치환**되어 그룹 붙여넣기 후 바인딩이 끊기지 않습니다. |
| 선택 노드 복제 | `Ctrl+D` = 복사+붙여넣기 한 방. 복사/복제 시 헤더에 "노드 N개 복사됨…" 안내가 잠깐 표시됩니다. |
| 💎 텍스트 복사 우선 | 화면에 텍스트를 선택해 둔 상태의 `Ctrl+C` 는 노드 복사가 아니라 **텍스트 복사**로 동작합니다(로그 본문 복사 등). |
| 키-값 행 복제 (⧉) | 쿼리/헤더/본문/폼 데이터 편집기의 각 행 ⧉ 버튼 — 키·값·타입·바인딩까지 복사된 행이 바로 아래 생깁니다. |
| Mock 라우트/규칙 복제 | Mock 에디터의 라우트·규칙에도 [복제] 버튼(내부 규칙까지 깊은 복사). |
| 대시보드 워크플로 복제 | 카드 ⋯ 메뉴 → ⧉ 복제 — "{이름} 복제본"이 **같은 폴더에** 생성됩니다. |

## 캔버스 — 추가·연결

| 기능 | 사용법 |
|---|---|
| 노드 추가 4종 | 팔레트 드래그 · 팔레트 클릭(중앙 배치) · 캔버스 더블클릭/우클릭(그 자리) · `Ctrl+K`(중앙). 메뉴는 검색 자동 포커스, **Enter = 첫 결과 추가**, Esc 닫기. |
| 💎 **엣지 빈 곳 드롭 = 노드 추가 + 자동 연결** | 핸들에서 선을 끌다 빈 곳에 놓으면 "연결할 노드 추가" 메뉴가 뜨고, 고르면 그 자리에 생기면서 원래 핸들(IF 분기 포트 포함)에 자동으로 이어집니다. |
| 연결 자석 | 핸들 반경 45px 안이면 자동 스냅 — 정확히 조준할 필요 없음. 연결 중에는 모든 핸들이 커지고 후광이 생깁니다. |
| 💎 엣지 끝점 리라우트 | 이미 연결된 엣지의 끝점을 잡아 다른 노드로 끌면 재연결됩니다(분기 포트 승계). 지우고 다시 그릴 필요 없음. |
| 엣지 × 삭제 | 모든 엣지 중앙의 × 버튼(엣지 선택 시 진해짐). `Delete`/`Backspace` 도 가능. |
| 💎 **IF T/F 칩 클릭 전환** | IF 에서 나온 엣지의 T/F 칩을 클릭하면 반대 갈래로 전환됩니다. 스위치 엣지의 트랙 칩도 클릭하면 다음 트랙으로 순환. |
| 💎 중복 연결 자동 차단 | 같은 포트→같은 대상 연결은 조용히 무시 — 유령 이중 실행이 안 생깁니다. |

## 캔버스 — 정렬·이동·보기

| 기능 | 사용법 |
|---|---|
| 💎 **다중 선택 정렬 툴바** | 노드 2개 이상 선택(Shift+드래그 박스 선택) 시 캔버스 상단에 정렬 툴바가 자동 등장 — 좌/중/우/상/중/하 정렬 6종. **3개 이상이면 가로/세로 균등 분배(↔/↕)** 버튼 추가. 가운데 정렬·균등 분배 결과는 그리드에 스냅되고, 모두 undo 가능. |
| 그리드 스냅 (22px) | 노드 드래그와 붙여넣기 오프셋이 22px 그리드에 맞춰집니다. 방향키 이동도 1칸(Shift=4칸). |
| 자동 정렬 | 도구 ⋯ → ⇥ 자동 정렬 — 그래프를 실행 순서(위상 레벨)대로 좌→우 재배치. 메모/영역은 건드리지 않고, undo 로 되돌릴 수 있습니다. |
| 💎 선택 영역 화면 맞춤 | 컨트롤의 ⛶ — 선택이 있으면 **선택 영역만**, 없으면 전체를 화면에 맞춥니다. 1:1 버튼은 줌 100% 리셋. |
| 💎 미니맵·그리드 토글 기억 | 컨트롤의 ▣(미니맵)/▦(그리드) 토글은 브라우저에 저장되어 다음에도 유지. 미니맵은 드래그/휠로 캔버스 탐색이 되고 노드가 카테고리 색으로 칠해집니다. |
| 노드 접기 | 노드 카드의 ▾ 로 헤더만 남기고 접기. 도구 메뉴에서 모두 접기/펴기. |
| 💎 메모 인라인 편집 | 메모(스티키 노트)는 패널을 열 필요 없이 **카드 안에서 바로 타이핑**하고, 내용만큼 자동으로 늘어납니다. |
| 💎 영역 박스 조작 | 본체는 클릭이 통과해 안의 노드 조작을 막지 않습니다 — **제목바로 이동**, **우하단 모서리로 리사이즈**(그리드 스냅, 최소 110×66). |
| 스위치 트랙 클릭 전환 | 캔버스의 스위치 노드 카드에서 트랙 행을 직접 클릭해 선로를 젖힙니다. |
| 💎 노드로 점프 | `Ctrl+F` 노드 검색(이름·타입·id) → 클릭/Enter 로 그 노드를 선택+센터링. ⚠ 문제 배지의 항목, 속성 패널의 ← 이전/다음 → 칩, 토큰 칩 `Alt+클릭` 도 모두 해당 노드로 점프합니다. |

## 속성 패널 — HTTP 를 빠르게

| 기능 | 사용법 |
|---|---|
| cURL 붙여넣기 | [cURL 붙여넣기] → curl 명령 그대로 적용(-X/-H/-d/--data-urlencode/-G/-u Basic 인증까지, -s/-L 등 무해 플래그 무시). 본문 타입도 자동 추정. |
| 프리셋 | GET/JSON/Form/Raw 버튼 — JSON/Form/Raw 는 메서드가 GET/HEAD 면 **POST 로 자동 승격** 후 본문 타입 전환(내용 실변환). 현재 상태와 일치하는 프리셋이 자동 하이라이트. |
| 💎 **쿼리스트링 → Params 분리** | URL 에 `?a=1&b=2` 를 붙여넣으면 "↳ 쿼리 N개를 Params 로 분리" 링크가 나타나고, 클릭하면 디코딩해서 Params 행으로 옮겨 줍니다. |
| [필드 ↔ Raw] 실변환 | Body·Params·Headers·폼 데이터 모두 — 토글하면 내용이 실제로 변환됩니다(파싱 실패 시 원문 보존+경고). Headers Raw 는 `Key: Value` 줄 형식이라 curl/브라우저 복사본을 그대로 붙일 수 있습니다. |
| 💎 본문 타입 변경 시 자동 변환 | JSON↔Form 등 구조형 간 전환 시 내용을 새 포맷으로 재직렬화 — "보이는 것=보내는 것"이 유지됩니다. |
| 요청 미리보기 | ▸ 요청 미리보기 — 실제 전송될 URL(쿼리 합침)·자동 부착 Content-Type(charset 포함)·본문을 그대로 보여줍니다. 💎 본문 섹션 상단에도 실제 전송 Content-Type 칩이 떠 있습니다. |
| 💎 **응답에서 출력 키 자동 채우기** | [▶ 이 노드만 실행] 후 응답이 객체면 "↧ 이 응답에서 키 채우기" 버튼이 나타남 — 응답 최상위 키들이 타입 추론까지 되어 출력 목록에 자동 추가됩니다. |
| 💎 응답 타입 전환 비파괴 | keyed→text/binary 로 바꿔도 기존 출력 키는 지워지지 않고 "무시됩니다" 경고만 — 되돌리면 그대로 복원. |
| 💎 섹션 스마트 접힘 | 쿼리(내용 있거나 GET이면 열림)/헤더(내용 있으면)/본문(항상)/응답(접힘) — 채워진 개수 배지 표시. |
| GET 본문 안내 | GET/HEAD 면 본문 섹션 대신 "조회 조건은 쿼리에" 안내가 나옵니다. |

## 속성 패널 — 입력·바인딩

| 기능 | 사용법 |
|---|---|
| 토큰 인라인 칩 | `{{ key@노드 }}` 가 입력란에서 아이콘+이름 칩으로 렌더 — 텍스트와 자유롭게 혼합(`https://[칩]/return`). 💎 손으로 토큰을 타이핑해도 포커스를 벗어나면 자동으로 칩이 됩니다. |
| 💎 칩 조작 | `Alt+클릭` = 소스 노드로 점프 · 일반 클릭 = 칩 바로 뒤에 캐럿 · 칩 포함 구간을 복사하면 **토큰 원문**이 클립보드에 실립니다. |
| 피커 키보드 | `{ }` 피커: 검색 자동 포커스, ↑↓ 이동, Enter 삽입 — **캐럿 위치에** 칩이 들어가고 포커스가 복귀합니다. |
| 💎 자동 노출 바인딩 | 선언 없이도 피커에 뜨는 것들: HTTP `httpStatus`, TCP 응답 필드 이름, wait 의 `url`(수신 URL — **그래프 어느 노드에서나**)·`body`, 환경 변수(`@env`)·실행 입력(`@input`)·시크릿(`@secret`) 그룹, 상위 노드의 **요청값**(`@req:` 태그). |
| 빠른 삽입 스니펫 | IF/ASSERT 조건식 아래 `≠ null` `== 200` `≠ 404` `== '0000'` `== true` 칩. |
| 긴 값 크게 편집 | 한 줄 입력이 넘치면 ⤢ 버튼이 나타나 큰 편집창으로 확장(저장은 그대로 한 줄). 패널 자체도 ⤢ 로 넓은 모달 편집 가능. |
| 💎 TCP 편의 | `host:port` 를 한 칸에 붙여넣으면 자동 분리 · 필드마다 `@오프셋` 배지+총 바이트 합계 · [+ 문자 필드]=공백 우측 패딩/[+ 숫자 필드]=0 좌측 패딩 관례 프리셋 · 응답 필드 이름이 곧바로 출력 키로 동기화. |
| 💎 변환(transform) 승계 | 변환을 바꿔도 같은 키의 입력값/설정은 승계되고, 같은 변환 재선택은 no-op — 실수 클릭으로 초기화되지 않습니다. |
| 💎 SET 시크릿 보기 토글 | 🔒 변수는 마스킹되지만 👁 버튼으로 행 단위 일시 표시. |
| 행 정렬/이동 | 순서가 의미 있는 목록(출력·입력 필드·TCP 필드)은 ▲▼ 로 재정렬. |

## 긴 목록 다루기 — 검색·일괄 입력 (2026-08-28)

노드·변수·시크릿이 수십 개로 늘어나도 고르기 쉽게 하는 장치들.

| 기능 | 사용법 |
|---|---|
| 💎 피커 최근 사용 | `{ }` 데이터 삽입 피커 맨 위에 **🕘 최근 사용**(최대 8개) — 방금 쓴 바인딩을 다시 집을 때 스크롤/검색 불필요. 지워진 노드/키는 자동 탈락. |
| 피커 섹션 접기 + 배지 | **기본은 접힌 상태**로 열려(소스 2개 이하면 자동 펼침) 칩 벽이 쏟아지지 않습니다 — 헤더의 항목 수 배지를 보고 클릭해 펼치거나(▾/▸) 바로 검색하세요. 한 소스에 12개 초과면 12개까지만 보이고 **+N개 더** 로 펼침. |
| 피커 검색 강화 | 키뿐 아니라 **노드 이름**으로도 검색되고, 매칭 부분이 하이라이트됩니다. ↑↓ 이동 시 화면 밖 항목은 자동 스크롤. `Esc` 1회=검색어 지움, 2회=닫기. |
| 환경 변수 검색·일괄 | 환경 관리: 변수 8개 이상이면 검색창 표시 · **📋 .env 붙여넣기**(`KEY=value` 여러 줄, 주석/`export`/따옴표 허용 — 같은 키는 값 갱신) · 환경 **⧉ 복제**(dev 복사해 staging 만들기) · 값 입력에서 `Enter` = 다음 행/새 행. |
| 💎 환경 변수 텍스트 모드 | 행을 하나씩 추가하는 대신 **[폼 ⇄ 텍스트] 토글**로 `.env` 텍스트를 통편집 — 한 줄에 `키=값`, 입력 즉시 폼/실행에 반영. 변수가 많을 때 가장 빠릅니다. |
| 화면 디테일 | 팔레트 노드 버튼은 **균일한 타일 폭**, 속성 패널 기본 폭 380px(최대 640) + 여백 확대, 모든 입력창에 **일관된 포커스 링/호버**, 가로 스크롤바는 가늘게 + 카드 미니 프리뷰에선 숨김(페이지 전체 가로 스크롤은 차단). |
| 💎 거의 전체화면 편집 | 속성 패널 ⤢(넓게 편집)는 **큰 모달**(1080px×92vh)로 열립니다. 긴 본문 — Mock 규칙 **응답 본문(HTML 결제창 템플릿)**·Mock 콜백 본문·wait **콜백 응답**·HTTP **raw 바디** — 은 textarea 우상단 **⤢** 로 전체화면 텍스트 편집기(글자 수 표시, 입력 즉시 반영, Esc 닫기)를 띄워 편집하세요. |
| 💎 코드 하이라이트·문법 체크 | 전체화면 편집기는 **HTML(안의 JS/CSS 포함)·JSON·XML 문법 하이라이트 + 문법 체크**(오류 밑줄·거터 ⚠, 줄번호·코드 접기)를 지원합니다 — 헤더의 언어 셀렉트로 전환(내용으로 자동 감지). `{{템플릿}}` 토큰이 경고로 표시될 수 있는데 실행에는 무해합니다. |
| 출력 키 일괄 추가 | HTTP 예상 응답 필드의 **📋 여러 키 추가** — `code, tid` 나열 또는 **샘플 JSON 응답을 통째로** 붙여넣으면 키+타입(number/boolean/array…)이 자동 추론됩니다(기존 키는 건너뜀). |
| 중복 키 경고 | 출력 키·헤더/바디 필드·환경 변수에서 같은 키가 두 번이면 주황 테두리 + 툴팁(마지막 값 적용 안내). 쿼리 Params 는 중복이 유효(`a=1&a=2`)라 경고하지 않습니다. |
| 시크릿 적용 표시 | 시크릿 볼트 목록에 활성 환경 기준 **✓ 적용 / 덮임** 배지 — 오버레이 우선순위(활성환경 > 공통 > Vault)가 한눈에. 다른 환경 스코프는 흐리게. 6개 이상이면 이름 검색. |
| Mock 라우트 검색 | 라우트 5개 이상이면 메서드/경로 검색창 — 순서(첫 매칭)는 그대로 유지된 채 화면만 좁혀 보여줍니다. |
| `Enter` 로 행 추가 | 출력 키·키-값·입력 필드·SET 변수의 마지막 행에서 `Enter` = 새 행 추가(환경 변수는 포커스 이동까지). |

## 조용히 지켜주는 것들 (안전장치)

- **이탈 경고**: 미저장 편집/실행 중에 탭을 닫으면 브라우저 확인 창이 뜹니다.
- **자동 저장(옵션)**: 도구 ⋯ 에서 켜면 편집 1.5초 후 자동 저장(설정 기억).
- **undo 히스토리 100개 + 병합**: 같은 노드 연속 타이핑은 900ms 묶음, 드래그는 시작 시 1회 스냅샷 — `Ctrl+Z` 한 번에 원위치.
- **협업 보호**: 원격 변경은 내 undo 를 오염시키지 않고, 저장 충돌(409)은 선택지를 주는 다이얼로그로.
- **입력 검증 인라인 경고**: 빈 URL/조건식/변환 미선택 등을 실행 전에 ⚠ 로 표시하고, 헤더 ⚠ 배지에 집계.
- **구버전 그래프 자동 마이그레이션**: 옛 wait 노드는 열 때 폼/입력 노드로 자동 승격되어 깨지지 않습니다.
- **단축키의 IME 내성**: 한글 모드에서도 물리 키 기준으로 동작. 접근성 — 상태 배지는 색+아이콘+텍스트 3중 부호화, OS '동작 줄이기' 설정 시 카메라 애니메이션 생략.
