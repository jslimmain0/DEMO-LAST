# FlowLink 사용 가이드

REST API 워크플로를 **만들고 · 실행하고 · 테스트**하는 사내 도구, FlowLink 의 사용 설명서입니다.
모든 스크린샷은 실제 앱 화면(데모 데이터)이며, 다크 모드 소개 컷(01장)을 제외하면 라이트 테마입니다.

## 어디서부터 볼까요?

| 처음이라면 | 기능을 깊게 알고 싶다면 |
|---|---|
| **[심플가이드](심플가이드.md)** — 10분 안에 첫 워크플로를 만들고 실행합니다. | 아래 **심화가이드** 챕터에서 필요한 부분만 골라 보세요. |
