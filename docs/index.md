# FlowLink 문서

REST API 워크플로 오케스트레이션 플랫폼 — 워크플로를 그려 실행하고, 미완성 API 는 내장 **Mock 서버**로
세워 전체 흐름을 먼저 테스트합니다. 자연어로 플로우를 만드는 **AI 어시스턴트** 내장. UI 는 전부 한국어.
