# 좁은 창의 배치·잘림 보완

사용자가 1차 디자인을 거절한 후 특히 배치와 잘림을 지적했다. 제품·디자인·에디터 담당이 논의해 추가 색상 교체를 보류하고 실제 입력 가독폭과 패널 배치를 우선했다.

## 재현과 수정

- 사용자 화면(1000×1244): 약 319px 속성 패널에서 응답 필드 이름이 거의 한 글자 폭으로 줄어들었다. 키·타입과 복사·사용처·정렬·삭제를 주행/보조행으로 분리했다.
- 좁은 에디터에서는 팔레트를 서랍으로 열고, 노드를 선택하면 일시적으로 닫는다. 저장된 팔레트 선호를 자동으로 덮어쓰지 않는다. 속성 패널은 360~400px 가독폭을 확보한다.
- 캔버스 크기가 바뀔 때 현재 배율로 작은 그래프 전체가 들어가면 전체를 최소 이동한다. 들어가지 않으면 선택 노드를 최소 이동한다. 미니맵 높이와 여백을 안전 영역에서 제외한다. 노드 좌표·배율은 변경하지 않고 수동 화면 이동을 계속 추적하지 않는다.
- 요청 필드의 키·값과 보조 작업도 분리했다. 실제 편집 영역 폭을 기준으로 열을 배치한다.
- 환경 목록은 1000px에서 220px를 확보해 긴 이름의 과도한 줄바꿈을 줄였다. 좁은 변수 편집 영역은 키·값을 두 줄로 배치한다.
- 제목·검색·작업 버튼은 폭에 따라 줄바꿈한다. 긴 모달은 화면 안에서 스크롤해 내용과 작업에 접근할 수 있도록 보완했다.

## 확인 결과

- 1000×1244 초기 선택: 캔버스 568px, 속성 패널 400px, 응답 키 입력 251px. 테스트 그래프 3개 노드 모두 캔버스 안에 표시.
- 800×720: 캔버스 408px, 속성 패널 360px, 응답 키 입력 211px. 가로 페이지 넘침 없음. 팔레트 서랍 오른쪽 200px/속성 패널 시작 440px로 겹치지 않음. 재열기 시 검색에 포커스.
- 1244px 높이에서 720px로 축소: 선택 노드가 캔버스 안에 남고 미니맵과 겹치지 않음. 노드 하단 546px/미니맵 상단 579px, 배율 1 유지.
- 900px 환경 화면: 키·값이 각각 약 349px 폭으로 다른 줄에 표시, 가로 넘침 없음.
- 800px 목록·설정 창과 1280px 복원 화면 확인. 기존 다크 테마 유지, 검증 뷰포트 복원.
- TypeScript/Vite 빌드, bootJar, 저장·미저장 이동 검사, 기하 회귀 12건 통과. lint 오류 없음(기존 Fast Refresh 경고 유지). 검증 세션 console error 없음.
- 개인 앱 18182와 Docker 서버 18080 모두 `index-Dm-9QkrH.js` 제공. MSI 재발행과 MCP 호출 테스트는 수행하지 않았다.

기존 워크플로·환경·계정 데이터를 수정하지 않고 검증했다. 팔레트·노드 선택·테마 외관을 위한 새 시드도 만들지 않았다. 모든 그래프를 작은 창 안에 강제로 축소하는 동작은 추가하지 않았으므로, 큰 그래프는 기존 확대/축소·화면 이동으로 탐색한다.
