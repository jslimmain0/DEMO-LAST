# 사용가이드 고도화(스크린샷 포함) — 설계 메모

날짜: 2026-08-12 · 브랜치: dev

## 목표
실사용자용 가이드를 **두 벌**로 재구성한다.
- **심플가이드** — 처음 쓰는 사람이 10분 안에 "워크플로 만들기 → 실행 → 결과 확인"까지. 단일 문서.
- **심화가이드** — 전 기능 챕터별 분할(에디터, 노드 레퍼런스, 바인딩, 실행·디버깅, 환경·입력·시크릿,
  트리거, 이력·스위트, 버전·협업, Mock 서버, 가져오기·내보내기, 설정·문제해결).

모든 문서는 **실제 앱 스크린샷**을 포함한다(브라우저 자동화로 촬영).

## 결정 사항 (사용자 확인 완료)
- 결과물: 저장소 Markdown + `docs/guide/images/*.png` (Git 관리, GitHub 렌더링)
- 구조: 챕터별 분할 + 심플/심화 2단 구성. 기존 `docs/사용가이드.md`는 요약+목차 허브로 유지.
- 범위: 전 기능 스크린샷 (~35장)

## 방법
1. 백엔드 H2(18080, 프론트 정적 포함) 기동.
2. Playwright(-core, 시스템 Chrome, 1440×900, 라이트 테마 고정)로 화면 촬영 → PNG 저장.
3. 데모 데이터 시딩(REST API): Mock 서버(결제 게이트웨이 + TCP 전문), 데모 워크플로 4개
   (사용자 조회/결제 승인/본인인증 콜백/TCP 전문), 폴더 2개, 실행 이력(성공·실패), 트리거, 시크릿.
   환경(env)은 localStorage(`fl:environments`) 시딩.
4. 각 PNG 를 열어 내용 검수 후 가이드에 임베드.

## 비범위
- 영문판, 동영상/GIF, 배포 자동화. 실제 외부 PG 연동 화면.
