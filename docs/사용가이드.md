# FlowLink 사용 가이드 (요약본)

REST API 워크플로를 **만들고 · 실행하고 · 테스트**하는 사내 도구입니다. 붙을 상대 시스템이 아직 없으면
내장 **Mock 서버**로 세워 전체 흐름을 먼저 검증할 수 있습니다.

> 📸 **스크린샷이 포함된 상세 가이드가 따로 있습니다** → [guide/README.md](guide/README.md)
> · 처음이라면 [심플가이드](guide/심플가이드.md) (10분 코스)
> · 기능별 심화는 [챕터 목차](guide/README.md#심화가이드-목차)
>
> 이 문서는 한 페이지 **요약본**입니다. 아키텍처·유지보수 정보는 [CLAUDE.md](https://github.com/jslimmain0/DEMO-LAST/blob/main/CLAUDE.md) 참고.

## 1. 5분 시작하기

1. **접속**: `http://localhost:18080` (또는 개발 모드 `http://localhost:5173`).
2. **워크플로 만들기**: 대시보드 → `+ 새 워크플로`. 빈 캔버스에 **시작(START)** 노드가 자동으로 놓입니다.
3. **노드 추가**: 왼쪽 팔레트에서 드래그, 또는 캔버스 **우클릭 / 빈 곳 더블클릭 / Ctrl+K** 로 검색해 추가.
4. **연결**: 노드의 동그란 핸들(●)을 드래그해 다음 노드에 잇습니다. 엣지를 **빈 곳에 놓으면** 그 자리에 노드가 생기며 자동 연결됩니다.
5. **실행**: 우상단 **▶ 실행**. 하단 실행 로그에 노드별 결과가 뜨고, 캔버스에 진행 애니메이션이 흐릅니다.
6. **저장**: **💾 저장** 또는 `Ctrl+S`. 저장할 때마다 **버전 스냅샷**이 쌓입니다.

> ⚠ 실행은 반드시 **START 노드에서** 시작해 엣지를 따라 흐릅니다. START 에 연결 안 된 노드는 **건너뜀(SKIPPED)** 되고,
> 캔버스에 점선 + `⚠ 미연결` 로 표시됩니다.

## 2. 화면 구성

| 화면 | 하는 일 |
|---|---|
| **대시보드** | 워크플로 목록·검색·폴더(탐색기식)·즐겨찾기. 폴더/선택 **일괄 실행**(스위트). |
| **에디터** | 캔버스에서 워크플로 편집·실행. 상단 도구(⋯) 메뉴에 부가 기능. |
| **실행 이력** | 과거 실행 조회(상태·기간 필터)·재실행·노드별 상세 재열람·이전 실행과 비교. |
| **Mock 서버** | 가짜 대상 시스템 정의·서빙(라우트·조건·응답·콜백·상태·TCP). |
| **⚙ 설정** | 콜백 수신 주소, 실패 알림 웹훅. |

## 3. 노드 종류

| 노드 | 용도 |
|---|---|
| **시작 / 끝** | 실행 시작점 / 종료점. |
| **HTTP 요청** | REST 호출. 서버(S→S) 또는 클라이언트(C→S) 모드. |
| **IF 조건** | SpEL 조건으로 **T/F 분기**(참이면 T, 거짓이면 F). |
| **검증(ASSERT)** | 조건이 **거짓이면 노드 실패** → 실행 FAILED. 테스트 판정용. |
| **스위치(선로)** | 조건 평가 없이 **사용자가 젖혀둔 트랙**으로만 흐르는 수동 라우팅(2~6갈래). mock↔실제 경로 전환 등. |
| **변수(SET)** | 변수 지정(리터럴·토큰·시크릿 마스킹). |
| **변환(TRANSFORM)** | 등록된 변환 플러그인(mask·hmac 등) 적용. |
| **TCP 전문** | 길이 프리픽스 고정길이 금융 전문(레거시 뱅킹). |
| **폼 전송(FORM)** | 결제/인증창을 새 창/iframe 으로 열어 폼 제출(기다리지 않고 진행). |
| **콜백 대기(WAIT)** | 외부 시스템 콜백을 **백엔드가 직접 받아** 자동 재개(브라우저 없이 완결·타임아웃). |
| **사용자 입력(INPUT)** | 실행 중 브라우저 모달로 값을 입력받아 다음 노드에 전달. |
| **메모 / 영역 박스** | 실행과 무관한 주석(스티키 노트 / 뒷배경 박스). |

**속성 패널**(노드 클릭)에서 타입별 설정을 편집합니다. `▶ 이 노드만 실행` 으로 그래프 전체를 안 돌리고 한 노드만 즉석 검증할 수 있습니다.

## 4. 토큰 바인딩 — 노드 사이에 값 넘기기

입력창에서 `{{ }}` 로 **다른 노드의 출력**을 꽂습니다. `{ }` 버튼(데이터 삽입)으로 피커에서 고르면 자동 완성됩니다.

| 문법 | 의미 |
|---|---|
| `{{ 키 }}` | 가장 가까운 **상위 노드**의 그 키 (nearest upstream) |
| `{{ 키@노드id }}` | **명시한 노드**의 그 키 |
| `{{ 키@req:노드id }}` | 그 노드의 **요청값** 스코프 |
| `{{ 키@env }}` | **활성 환경**의 변수 (아래 §6) |
| `{{ 키@input }}` | **실행 입력** 파라미터 (§7) |
| `{{ 이름@secret }}` | **시크릿 볼트** 값 (§8) — 로그엔 마스킹됨 |
| `{{ state.키 }}` | (Mock) 서버 상태값 (§12) |

- URL 은 **한 필드**에 통째로: `https://api.example.com/{{ orderId@조회 }}/detail`.
- HTTP 응답에서 상태코드는 `{{ httpStatus@노드 }}` 로 검증: `{{ httpStatus@조회 }} == 200`, `!= 404`.
- 값이 **정확히 토큰 하나**면 숫자/불리언/객체 **원형**이 보존됩니다(타입 유지).

## 5. 실행 & 디버깅

- **실행 로그**(하단): 노드별 상태 배지(✓/✕/⊘/스피너) + 요청/응답/출력. **필터**(전체/성공/실패/건너뜀), **복사**, **.txt 내보내기**. 실패 시 첫 실패 노드가 자동으로 펼쳐집니다.
- **진행 애니메이션**: 지나간 엣지=녹색, 진행 중=움직이는 점선, 실패=빨강, 건너뜀=반투명.
- **단일 노드 실행**: 속성 패널 `▶ 이 노드만 실행`(이력 미저장, 상류 바인딩은 null).
- **콜백 대기 표시**: WAIT 노드는 카운트다운 + 수신 URL + 펄스를 보여주며, 콜백이 오면 자동 완료됩니다(탭을 닫아도 서버가 완결).

## 6. 환경(Environment) — dev/staging/prod 전환

baseUrl·토큰을 노드마다 고치지 말고 **환경 변수**로 빼서 한 번에 바꾸세요.

1. 에디터 상단 **🌐 환경** → `환경 관리` → 환경(예: `dev`, `prod`) 만들고 변수(예: `baseUrl = https://dev.api…`) 추가.
2. 라디오로 **활성 환경** 선택.
3. 노드 입력에 `{{ baseUrl@env }}` 처럼 꽂으면 실행 시 활성 환경 값이 주입됩니다.

> 환경은 **브라우저(개인)** 에 저장됩니다(팀 공유 아님). 팀 공유·민감값은 **시크릿 볼트**(§8)를 쓰세요.

---

## 7. 실행 입력 파라미터 — 같은 워크플로, 다른 입력

도구(⋯) → **▶ 입력값과 실행** → 키/값 입력 → 실행. 값은 `{{ 키@input }}` 로 참조됩니다. 플로우별로 저장돼 다음에 재사용됩니다.
(회귀 테스트를 다른 입력으로 반복할 때 유용.)

---

## 8. 시크릿 볼트 — Bearer/API 키 안전하게

도구(⋯) → **🔑 시크릿 볼트** → 이름·값 저장. 사용은 `{{ 이름@secret }}`.

- 값은 **암호화 저장**(다시 볼 수 없음, 이름만 목록에 표시).
- 실행 로그·DB 에는 **마스킹(••••••)** — URL 인코딩·JSON 이스케이프 변형까지 가려집니다.
- **서버(S→S) 모드** HTTP 노드에서 쓰세요. 클라이언트(C→S) 모드는 값이 브라우저로 전달돼 대기 상태에 남을 수 있습니다.

---

## 9. 자동 실행 트리거 — 스케줄 / 웹훅

도구(⋯) → **⏰ 자동 실행 트리거**. 실행은 **서버가 구동**하므로 브라우저를 켜 둘 필요가 없습니다.

- **스케줄(cron)**: `초 분 시 일 월 요일`(6필드). 프리셋(매시 정각·매일 03:00·평일 09:00 등) 제공. 다음 실행 시각이 표시됩니다.
- **웹훅**: `웹훅 URL 발급` → 외부 시스템이 `POST {URL}/hooks/{token}` 하면 실행. 본문(JSON)은 `{{ 키@input }}` 로 주입됩니다.
- 각 트리거는 **켜짐/꺼짐** 토글, 삭제 가능.

> ⚠ 단일 인스턴스 스코프(스케줄러). 스케줄 실행은 접속 오리진이 없으므로 콜백 수신 주소는 ⚙ 설정/env 로 지정하세요.

---

## 10. 실행 이력 · 재실행 · 스위트

- **실행 이력** 화면: 상태(성공/실패/대기/취소)·**기간**(24h/7d/30d) 필터 + 이름 검색. 행 클릭 → 노드별 상세 재열람.
- **↻ 재실행**: 원본 버전+입력 그대로 다시 실행.
- **⇄ 이전 실행과 비교**: 같은 워크플로 직전 실행과 노드별 응답을 **변경/동일/신규**로 비교(회귀 확인).
- **스위트 일괄 실행**(대시보드): 폴더 안에서 **▶ 폴더 실행**, 또는 선택 모드에서 **▶ 선택 실행** → 성공/실패 **매트릭스**.

## 11. 버전 관리 & 협업

- **버전 기록**(도구 ⋯ → 🕘): 저장할 때마다 쌓인 스냅샷 목록 + **현재와 diff**(노드/연결 added/removed/changed) + **이 버전으로 복원**(불변 이력 유지 — 되돌린 것도 새 버전).
- **실시간 협업**: 같은 워크플로를 연 사람끼리 **커서·이름표·편집중 배지·저장 알림**이 보이고, 편집이 실시간 반영됩니다(비CRDT last-write-wins — 정확히 동시 편집은 드물게 마지막이 이김).
- **워크스페이스 & 권한**: 폴더 위 상위 그룹 — 🌐 공용(모두 편집) / 🔒 개인(자동 생성) / 👥 팀(OWNER·EDITOR·VIEWER 롤). 사이드바 셀렉트로 전환하며 워크플로·폴더·Mock·실행 이력이 분리됩니다. GitHub **로그인 = 가입 신청** → 관리자가 🛡 관리 콘솔(/admin)에서 승인/차단. ⚙ 다이얼로그의 **워크스페이스 이동**으로 폴더·워크플로·Mock 을 JSON 텍스트 복붙으로 통째 복제. 상세: [가이드 16장](guide/16-워크스페이스-권한.md).

## 12. Mock 서버 — 가짜 대상 시스템 세우기

상단 **Mock 서버** 탭에서 미완성/외부 시스템을 흉내 냅니다. 저장 즉시 `http://localhost:18080/mock/{slug}/**` 로 서빙.

- **라우트**: method + 경로(`/users/{id}`)마다 규칙 정의.
- **조건(when)**: `source`(query/header/body/path/**state**) + `eq/ne/exists/contains` (AND, 정의순서 첫 매칭).
- **응답 템플릿**: `{{path.x}}` `{{query.x}}` `{{body.x}}` `{{header.x}}` `{{state.x}}` `{{uuid}}` `{{seq}}` `{{now}}`. charset·지연·contentType 지정.
- **콜백 발사**: 응답 후 지정 URL 로 웹훅(승인/입금 노티 패턴).
- **상태 있는 목**: 규칙에 `setState`(키·값) → 다음 호출의 조건/템플릿에서 `{{state.키}}`/`source=state` 로 읽힘. 예) **1차 호출 pending + setState → 2차 호출 approved**.
- **TCP 전문 목**: spec 의 `tcp` 섹션(포트·문자셋·길이 프리픽스·contains 규칙).
- **원클릭 테스트**: 라우트 옆 ▶ 로 즉석 호출. **OpenAPI → 라우트 자동 생성** 지원.

워크플로 HTTP 노드의 URL 에 이 mock base 를 넣어 호출하면, 상대 시스템 없이 전체 흐름을 검증할 수 있습니다.

> ⚠ mock 상태·seq 는 인메모리(재시작 리셋). 범용 무상태 목이 기본이며, setState 는 회차/플래그 수준 시나리오용입니다.

## 13. 가져오기 / 내보내기

에디터 상단 **가져오기**(탭 하나) — 세 가지 소스:
- **워크플로 JSON**: 파일/붙여넣기 → 캔버스 교체.
- **OpenAPI / Swagger**: 스펙(URL/파일/붙여넣기)에서 오퍼레이션 선택 → 팔레트에 추가.
- **cURL**: `curl …` 명령 → HTTP 노드 하나 생성(메서드·URL·헤더·본문 반영).

**내보내기**: 현재 그래프 JSON 복사/다운로드. (노드 속성 패널에서 `cURL 로 복사`도 가능 — 토큰은 그대로 실린 템플릿.)

## 14. 실패 알림

## 15. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 노드가 실행 안 됨(건너뜀) | START 에서 엣지로 **연결** 안 됨. 캔버스 `⚠ 미연결` 점선 확인. |
| 바인딩이 비어 있음 | 응답 타입(키형/통짜형)에 맞는 키인지 확인. 통짜형(text/binary)은 `{{ body@노드 }}`. 헤더 상단 `문제 요약(⚠)` 배지 클릭 시 해당 노드로 점프. |
| 한글이 깨짐(레거시) | HTTP 노드 **charset**(EUC-KR/MS949) 지정. 단, 클라이언트 모드는 브라우저 UTF-8 제약 → **서버 모드** 권장. |
| 콜백이 안 옴 | ⚙ 설정의 **콜백 수신 주소**가 외부에서 도달 가능한지 확인(프록시/터널 뒤면 명시 필요). |
| 단축키가 안 먹음(한글 모드) | 물리 키(`e.code`) 기준이라 정상 동작해야 함. 입력창 포커스 중엔 브라우저 기본에 양보. |
