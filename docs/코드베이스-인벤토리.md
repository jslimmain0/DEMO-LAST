# FlowLink 코드베이스 인벤토리

모듈·패키지·파일별 **기능**과 **존재 필요성**을 정리한 문서. 5영역(백엔드 실행엔진 / 백엔드 나머지 / 프론트 앱·데이터 / 프론트 캔버스·편집 / 리포 도구·자산)을 코드 실측(grep 참조 확인)으로 분석했다.

**필요성 등급**
- **essential** — 핵심 필수. 제거 시 기능 붕괴.
- **optional** — 특정 기능/노드 타입 전용. 그 기능을 쓸 때만 필요.
- **redundant** — 중복·과잉 export. 내부에서만 쓰이거나 대체 경로 존재.
- **questionable** — 미사용·미완성·제거 후보.

> 진실원은 [CLAUDE.md](../CLAUDE.md). 이 문서는 "무엇이 있고 왜 있는가 + 없어도 되는가"에 초점.

## 0. 아키텍처 한눈에

```
브라우저 (React/Vite :5173)
  ├─ routes: Dashboard · Editor · Executions · MockServers · MockServerEditor
  ├─ 캔버스 상태 = Zustand(editorStore) / 서버 데이터 = React Query
  └─ 실행 오케스트레이션(Editor.onRun): run → pending(form/wait/input/client) → resume 루프
        │  wait 콜백 ↕ relay.js(:8787)          form 팝업/iframe · input 모달 = 브라우저
        ▼
백엔드 (Spring Boot :18080)  — 모듈러 모놀리스
  ├─ definition  플로우 CRUD·버전·import        ├─ execution  FlowExecutor + 노드 실행기 + SSRF 가드
  ├─ folder      폴더                            ├─ mock       가짜 대상 시스템 /mock/{slug}/**
  ├─ transform   변환 SPI + JAR 플러그인          ├─ security   OIDC 골격 + 테넌트
  ├─ common      error·json·tenant·openapi        └─ core       도메인·그래프·리포지토리
        ▼ H2(dev, 파일) / Postgres(prod, Flyway)
리포 도구:  relay.js(콜백 수신) · mock-server.js(데모 대상) · demos/ · flowlink-workflow/(AI 스킬) · .github/(Copilot)
```

핵심 실행 축: **FlowExecutor**(Kahn 위상정렬 동기 오케스트레이터) — 브라우저 협업 노드(client HTTP/FORM/WAIT/INPUT)에서 `WAITING`으로 중단하고 `resume`으로 이어가는 재개 프로토콜(인메모리 `RunState`).

## 1. 백엔드 — 실행 엔진 (`core` + `execution`)

거의 전부 **essential**. FlowExecutor를 정점으로 노드 실행기·토큰 해석·표현식 평가·SSRF 가드가 협력한다.

| 모듈 | 기능 | 필요성 |
|---|---|---|
| `execution/engine/FlowExecutor.java` | 그래프를 위상정렬 순 실행. IF 단일 분기, 첫 실패 중단, 협업 노드 WAITING 중단·재개(`drive`/`resume`/`RunState`) — 계열 최대(654줄) | **essential** |
| `execution/engine/ExecutionContext.java` | 노드 출력/요청값 삽입순 누적. `values`(nearest-upstream) vs `seeds`(wait URL 선시드) 이원 저장 | **essential** |
| `execution/engine/TokenResolver.java` | `{{key}}`·`{{key@id}}`·`{{key@req:id}}` 토큰/바인딩 해석. HTTP/TCP/SET/transform/IF가 의존 | **essential** |
| `execution/engine/ExpressionEvaluator.java` | IF/ASSERT 조건 안전 평가(SpEL `SimpleEvaluationContext` 읽기전용 + 길이·토큰 상한). 인젝션·DoS 방어 | **essential** |
| `execution/engine/HttpNodeExecutor.java` | HTTP 노드 `build`/`execute`/`clientResult`, respType 파싱, EUC-KR/MS949 charset, XXE 차단 (510줄) | **essential** |
| `execution/engine/TcpNodeExecutor.java` | 고정길이 금융 전문(BAL1) — 바이트 조립·길이 프리픽스·응답 슬라이싱 | **optional**(TCP 노드 전용) |
| `execution/engine/SsrfGuard.java` | HTTP/TCP 전송 전 SSRF 방어(스킴/호스트/사설·루프백·링크로컬·CGNAT·ULA 대역) | **essential** |
| `execution/engine/NodeResult · NodeRecorder · SsrfBlockedException` | 노드 결과 레코드 / 짧은 트랜잭션 영속화 콜백 / 차단 예외 | **essential** |
| `execution/ExecutionService.java` | 실행 진입점 + 영속화 경계. `run`/`resume`, 재개 상태(`suspensions` 인메모리), wait URL 시드, redaction (338줄) | **essential** |
| `execution/ExecutionController.java` | `POST /flows/{id}/runs`·`POST /executions/{id}/resume`·이력/로그 조회 | **essential** |
| `execution/config/ExecutionProperties · HttpClientConfig` | `flowlink.execution.*` 설정 / 아웃바운드 RestClient 타임아웃 빈 | **essential** |
| `execution/dto/*` | RunRequest·ResumeRequest·ExecutionDetail·Pending{Client,Form,Wait,Input}Request 등 컨트롤러↔서비스 계약 | **essential** |
| `core/domain/*` | Flow→FlowVersion(불변 스냅샷)·Execution→NodeExecution·Folder. UUID+tenant_id, 낙관적 락 | **essential** |
| `core/graph/*` | graphJson 타입드 뷰 — FlowGraph/GraphNode/GraphEdge/NodeType/GraphValidator + 값 레코드. `effectiveType()` 하위호환 | **essential** |
| `core/repository/*` | Spring Data JPA — 전부 tenant_id 필터. `findByIdAndTenantId`가 테넌시 격리 경계 | **essential** |

## 6. "있을 필요 없는 것" — 정리 권장 (우선순위)

이 세션에서 **참조 0으로 검증된 데드코드는 이미 제거**했다(별도 커밋). 아래는 그 이후 남은 재고 대상.

### A. 즉시 제거 가능 (진짜 죽은 코드 — 리스크 없음)
| 대상 | 근거 |
|---|---|
| `frontend/src/App.css` | Vite 템플릿 스캐폴딩 잔재(.counter/.hero 등). **어디서도 import 0** — 번들에 포함조차 안 됨 |
| `editorStore.addNodes` | 인터페이스+구현 있으나 호출 소비자 0 (노드 추가는 addNode/addNodeFromTemplate) |
| `upstream.ts`의 `upstreamSources` export · `schema.ts`의 `mapType`/`resolveRef` export | 모듈 내부에서만 사용 — `export` 키워드만 제거(과잉 export) |

### B. 결정 필요 — `lib/validation.ts` ⚠ (숨은 버그성 갭)
- **미사용**: `validateGraph`(사이클·중복id·dangling 검증)가 리포 전체에서 import 0.
- **문제**: 설계상 "사이클 검증은 프론트 단독 책임"인데 **저장/실행 경로에 연결돼 있지 않다.** 백엔드도 사이클 미검증 → **순환 그래프가 실행 엔진까지 도달할 수 있는 갭**.
- **권장**: (a) `Editor.tsx`의 저장/실행 직전에 `validateGraph` 배선(안전망 복구) — **권장**, 또는 (b) 정말 불필요하면 삭제(그러면 사이클 안전망 영구 포기).

### C. 미완성 기능의 백엔드 선반영 (제거보다 대기 — 프론트 UI 추가 시 필요)
| 대상 | 상태 |
|---|---|
| `FlowController.export` | 내보내기는 프론트가 클라이언트에서 직접 직렬화 → 백엔드 export 미사용 |
| `FlowController.versions`/`versionGraph` | 버전 히스토리 UI 부재 → 미사용(롤백 UI 추가 시 필요) |
| `FlowController.update`(PATCH) | 이름은 saveVersion의 graph.name으로 갱신 → 메타 PATCH 미사용 |
| `TransformController.reload` | 업로드가 내부에서 reload 호출 → 수동 reload 중복 |
| enum `ExecutionStatus.PENDING`·`NodeExecutionStatus.WAITING`·`TriggerType.SCHEDULE/WEBHOOK/EVENT` | 로드맵 placeholder(비동기 큐·트리거 미구현) — 주석 명시 권장 |

### D. 보안 부채 (제거 아님 — 운영 전 하드닝 필수)
| 대상 | 리스크 |
|---|---|
| 플러그인 JAR 샌드박스 부재 + permitAll | 업로드 JAR가 전체 권한 실행 → 운영 노출 시 RCE. RBAC 게이트·샌드박스 필요 |
| Mock 게이트웨이 무인증(`/mock/**`) + `/__routes` 디버그 | 내부망 전제로 의도적. 외부 노출 시 slug 추측·정보 노출 |
| SSRF DNS 리바인딩 갭 | check-time 해석만, connect-time IP 핀닝 미적용 |

### E. 중복·재고 (통합보다 "역할 경계 문서화"가 안전)
| 대상 | 판단 |
|---|---|
| `backend/scripts/*.sh` | .ps1과 완전 중복(Windows 전용 프로젝트). 크로스플랫폼 확정 아니면 유지, 확정이면 제거 |
| `.github/` Copilot 지침 | 플러그인과 기능 중복. Copilot 미사용이면 프롬프트 슬림화 |
| `mock-server.js` ↔ 내장 Mock | 개념 중첩이나 TCP·stateful은 내장이 못 함 → 통합 시 데모 회귀. 유지 |
| `scripts/dev-all` | 기존 개별 실행과 중복이나 온보딩 순가치 → 유지 |

## 요약

- **런타임 코어**(백엔드 실행엔진·정의·mock·common, 프론트 앱·캔버스)는 **거의 전부 essential**이고 중복이 없다.
